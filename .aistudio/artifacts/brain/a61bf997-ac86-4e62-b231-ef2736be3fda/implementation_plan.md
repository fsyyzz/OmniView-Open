# OmniView Excalidraw PC 端专业手绘白板工作室方案

将当前仅支持静态预览的 Excalidraw 画布升级为**面向 PC 桌面端深度优化的专业手绘架构画板工作室（Excalidraw PC Studio）**。依托零外部重依赖的自研轻量手绘几何与交互引擎，提供媲美桌面原生绘图软件的键鼠效率、智能磁吸连线、多选对齐分布、三栏专业停靠工作台与 100% `--ov-*` 主题自适应体验。

## 用户评审与已确认核心决策

> [!IMPORTANT]
> 以下核心架构与交互方案已根据第一阶段确认项锁定，确认本方案后即可直接进入工程实现。

- **底层引擎路线（已确认）**：**自研轻量手绘交互引擎**，零外部重型依赖，基于确定性随机种子（Seeded Roughness）生成手绘抖动 SVG 路径、Hachure 斜线阴影填充与连线箭头，秒级加载且 100% 融合 `--ov-*` 语义化主题令牌。
- **工作台界面布局（已确认）**：**经典桌面专业三栏布局** —— 顶部绘图工具坞与快捷动作栏 + 左侧可折叠「图层树 / 画框大纲 / 架构素材」多页签侧栏 + 中央无限交互画布（含右下角鹰眼小地图 Minimap）+ 右侧上下文「属性与对齐检查器（Inspector）」。
- **PC 核心交互全集（已确认）**：
  1. 全套单键工具切换与 PC 键鼠组合（空格按住临时抓手拖拽、Ctrl/滚轮光标中心焦点缩放、Ctrl+Z/Y 撤销重做、Ctrl+C/V/D 复制克隆、Ctrl+G/Shift+G 编组与解组、Alt+拖拽快速复制）。
  2. 智能辅助参考线（Smart Guides）磁吸对齐、多选 8 向对齐与等距分布。
  3. 箭头/连线北南东西 4 锚点磁吸绑定（节点移动或缩放时，绑定连线自动实时重算正交/直线路径）。
  4. 双击图元或画布原地内联文本编辑（自动绑定容器文字 `boundElements` 或创建独立文本图元）。
  5. 画布右键上下文菜单、图层树拖拽/显隐/锁定管理与右下角可交互鹰眼小地图（Minimap）。

## 1. 总体概览与核心定位

- **核心能力**：在 OmniView 浏览器工作台与 VS Code 插件环境中，为用户提供开箱即用的 PC 桌面级 Excalidraw 架构图与手绘白板生产力工具，同时保留双向分屏（JSON 源码 + 实时画布）、Mermaid 一键转译手绘、Frame 幻灯片演播以及 `.excalidraw.svg` 自包含双模交付。
- **目标用户场景**：软件架构师、后端/前端工程师在 PC 大屏上使用键鼠高频绘制系统拓扑图、微服务调用链、业务领域故事与技术方案草图。
- **核心价值跃升**：从“只能看和改 JSON 的静态预览器”彻底进化为“单手键盘切工具、鼠标拖拽连线磁吸、右键管理层级、面板精调手绘质感”的完整 PC 画板生产力闭环。

## 2. 用户体验与视觉设计 (UX & Visual Identity)

### 2.1 核心用户交互流 (PC Desktop Workflows)

1. **单键极速绘图流**：
   - 按下键盘单键（`V`/`1` 选择、`H` 抓手、`R`/`2` 矩形、`D`/`3` 菱形、`O`/`4` 椭圆、`A`/`5` 箭头、`L`/`6` 线条、`P`/`7` 自由画笔、`T`/`8` 文本、`F` 画框 Frame、`E` 橡皮擦）立即切换顶部工具坞激活态。
   - 在画布拖拽即可实时预览手绘几何包络与尺寸浮标（`tabular-nums` 显示实时宽高 `W × H`）；支持按住 `Shift` 等比锁定正方形/正圆/45° 正交连线；绘制完成后默认自动回切选择工具（支持「锁定当前工具连续绘制」开关）。
2. **智能磁吸连线与拓扑跟随流**：
   - 切换箭头工具（`A`）移近任意图元时，图元四周浮现北/南/东/西及中心磁吸锚点光晕（Snap Port Halo）。
   - 拖拽连线首尾吸附至目标图元后，自动写入 Excalidraw 标准 `startBinding` / `endBinding` 与节点 `boundElements`；后续拖拽任意节点时，所有关联箭头实时跟随重算坐标。
3. **原地双击内联文字流**：
   - 双击任意几何容器（矩形/菱形/椭圆/箭头）内部，直接在图元中心弹出透明自适应内联输入框，回车或失焦后自动生成并绑定容器内居中文字；双击空白画布则直接创建独立手绘文字图元。
4. **框选、智能吸附与多选排版流**：
   - 选择工具在空白处拖拽拉出半透明选区框（Rubber-band Selection），支持 `Shift+点击` 增减选中图元。
   - 选中单/多图元时展示 8 方向缩放控制手柄（Resize Handles）与顶部旋转手柄；拖拽移动过程中实时计算与其他图元边缘/中心线的对齐关系，绘制高亮智能参考线（Smart Snap Guides）并轻微磁吸。
5. **右键上下文菜单与鹰眼漫游流**：
   - 在画布或图元上右键呼出桌面级快捷菜单（复制、粘贴、克隆 `Ctrl+D`、置于顶层/上移一层/下移一层/置于底层、编组/解组、锁定/解锁、收藏至本地物料库、删除）。
   - 右下角常驻可折叠鹰眼小地图（Minimap），实时缩略展示全量图元与当前视口矩形框，支持点击或拖拽视口框在大画布中极速漫游。

### 2.2 视觉体系与主题融合规范

- **美学定位**：专业桌面级工程创作工具（Utilitarian Desktop Creative Studio），60% 纯净画布视野 + 30% 结构化停靠面板 + 10% 语义高亮强调色。
- **100% `--ov-*` 主题令牌驱动**：
  - 严禁散落硬编码深浅色值，所有工具栏、左右停靠栏、右键菜单、小地图与浮动标尺统一采用 `--ov-bg`、`--ov-surface`、`--ov-surface-header`、`--ov-border`、`--ov-text`、`--ov-text-secondary`、`--ov-accent`。
  - 画布点阵/网格背景根据主题动态计算微妙对比度，支持画布手绘色彩预设调色盘与自定义色值。
- **排版与等宽数字规范**：
  - 界面控制标签严格执行单行不折行（`whitespace-nowrap shrink-0`）。
  - 所有坐标（`X`, `Y`）、尺寸（`W`, `H`）、角度（`°`）、透明度（`%`）、缩放倍率与统计数字全面启用等宽对齐数字（`font-mono tabular-nums`），彻底杜绝拖拽过程中的数字抖动。

## 3. 关键产品与技术决策 (Key Decisions & Trade-Offs)

- **决策 1：基于确定性随机种子（Seeded PRNG）的手绘矢量渲染器**
  - *方案*：自研轻量级 Rough SVG 生成算法，依据每个图元的 `seed`、`roughness`（0 精准几何 / 1 标准手绘 / 2 狂野涂鸦）、`fillStyle`（`hachure` 手绘排线 / `cross-hatch` 交叉排线 / `solid` 纯色）与 `roundness` 实时计算 SVG `<path>` 双重描边与排线填充。
  - *优势*：零外部重包体积开销，同一 `seed` 在拖拽缩放时笔触形态稳定不闪烁，且导出的 `.svg` / `.excalidraw.svg` 与画布所见 100% 一致。
- **决策 2：命令历史栈（Command History）与手势节流同步**
  - *方案*：在指针按下并拖拽（PointerMove）期间仅更新内存态瞬时坐标以保证 60 FPS 丝滑帧率；在指针释放（PointerUp）或完成内联编辑时统一压入 Undo/Redo 历史栈（容量 100 步）并触发 `onContentChange` 同步回写。
  - *优势*：避免拖拽过程中高频 JSON 序列化阻塞主线程，同时确保每次拖拽/缩放/属性修改都能通过 `Ctrl+Z` / `Ctrl+Y` 精确回退一整个原子操作。
- **决策 3：完全兼容官方 Excalidraw v2 JSON 协议**
  - *方案*：所有图元增删改、群组 `groupIds`、容器文字 `containerId`、箭头绑定 `startBinding`/`endBinding`、画框 `frameId` 均严格读写标准 Excalidraw v2 JSON 字段。
  - *优势*：在 OmniView 中编辑保存的 `.excalidraw` 或 `.excalidraw.svg` 文件可与外部生态无缝互通。

### 4.2 核心状态模型与交互映射

| 交互模块 | 核心状态与数据结构 | 完整事件处理与闭环行为 |
|---|---|---|
| **工具坞与单键快捷键** | `activeTool`: `'select' \| 'hand' \| 'rectangle' \| 'diamond' \| 'ellipse' \| 'arrow' \| 'line' \| 'freedraw' \| 'text' \| 'frame' \| 'eraser'`，`keepToolActive`: `boolean` | 监听全局键盘单键（排除输入框焦点态）切换工具；支持按住 `Space` 临时激活 `hand` 抓手模式，松开自动恢复原工具。 |
| **指针绘制与几何变换** | `interactionState`: `'idle' \| 'panning' \| 'drawing' \| 'moving' \| 'resizing' \| 'rotating' \| 'marquee'`，`selectedIds`: `Set<string>` | 支持空白框选、单选/Shift多选、8 向控制点缩放、旋转手柄旋转、拖拽移动；移动/缩放结束时自动更新关联绑定文本与箭头路径并写入 Undo 栈。 |
| **智能吸附与参考线** | `snapGuides`: `Array<{ type: 'vertical' \| 'horizontal', pos: number, start: number, end: number }>` | 拖拽移动或缩放图元时，实时对比画布其他未选中图元的左/中/右、上/中/下坐标（容差 5px），生成视觉辅助线并吸附坐标。 |
| **连线磁吸与拓扑跟随** | `hoveredAnchor`: `{ elementId: string, port: 'n' \| 's' \| 'e' \| 'w' \| 'center', x: number, y: number } \| null` | 绘制或拖动箭头端点靠近节点时高亮锚点并吸附；节点发生位移或尺寸变化时，自动遍历关联 `arrow` 重算首尾点坐标。 |
