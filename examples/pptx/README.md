# OmniView PowerPoint (.pptx) 示例演示文稿

本目录包含 OmniView 针对微软 PowerPoint (.pptx / OOXML 演示文稿) 规范的标准示例文件。

## 📊 包含文件

- **`omniview-tech-presentation.pptx`**: OmniView 技术演播高保真示例文档。
  - **Slide 1 (封面页)**: 16:9 宽屏比例、大标题、副标题、品牌主色矢量装饰圆角矩形，配套开场演讲者备注；
  - **Slide 2 (架构特性与图文页)**: 包含内嵌图片引用 (`image1.png`)、项目符号列表、矢量色块卡片，配套架构讲解备注；
  - **Slide 3 (数据对比与矩阵页)**: 包含标准 3x3 格式化数据表格、单元格文字与背景着色，配套收尾互动建议备注。

## 🎮 确认可用的 8 项核心操作

1. **幻灯片多维度翻页控制器**：
   - 顶栏上一张 / 下一张按钮（到首页/尾页智能置灰）；
   - 键盘方向键：`←` / `PageUp` 上一张，`→` / `Space` / `PageDown` 下一张；
   - 快捷键首尾跳转：`Home` 一键回首页，`End` 一键跳尾页。
2. **幻灯片等比缩略图大纲列表**：点击顶栏「大纲」按钮展开/折叠 16:9 缩略图卡片列表，点击任意卡片秒级切页；
3. **演讲者备注浮动抽屉 (Speaker Notes)**：点击「备注」按钮展开演播提词抽屉，自动跟随当前页码切换提词，无备注时友好展示兜底提示；
4. **全屏沉浸演播放映**：点击「放映」按钮或按快捷键进入全屏放映，支持全屏下全套快捷键翻页；
5. **重新载入与解析刷新 (Refresh)**：点击刷新按钮实时重新触发解析流水线；
6. **文稿出版元数据抽屉**：点击「信息」按钮查看文稿名称、演讲者、画布比例与物理尺寸 (pt)、总页数与文件大小；
7. **四大类矢量图元高保真渲染**：文本框富文本、纯几何形状 (矩形/圆角/圆形/线条)、内嵌媒体图片、3x3 格式化表格；
8. **损坏数据自愈降级防御**：遇到空数据或损坏文件时自动降级呈现内置高保真幻灯片，杜绝白屏。
