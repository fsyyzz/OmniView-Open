# 图像工作台示例套件 (Image Examples)

本目录包含 OmniView 原生现代图像工作台与像素检视器 (`ImageViewer`) 的典型高保真示例图片，用于验证图片多尺度缩放、16x 十字像素取色器、全景底色模式与沉浸式工具栏折叠能力。

---

## 🖼️ 样例文件列表

| 文件名 | 格式 | 尺寸 | 典型测试功能 |
| --- | --- | --- | --- |
| **`omniview-brand-logo.png`** | PNG (8-bit RGB) | 1024 × 1024 | 矢量与光栅图形检视、16x 像素放大镜取色 (HEX / RGBA / HSLA)、四态底色模式 (系统底色/暗室/明亮/棋盘格)、一键复制 Base64 Data URI |
| **`cyberpunk-city-skyline.jpg`** | JPEG (JFIF) | 1376 × 768 (16:9) | 宽屏高分辨率照片渲染、10%~3200% 极清平滑无级缩放、沉浸式右上角微型折叠胶囊切换、全屏沉浸浏览 |

---

## 🎯 推荐验证操作

1. **纯净沉浸式浏览体验**：
   - 打开上述任意图片，默认处于沉浸看图模式，顶部无重型通栏 Header 遮挡；
   - 观察右上角浮动的半透明微型胶囊（实时显示当前缩放百分比，并提供「工具栏」展开按钮）；
   - 使用滚轮平滑缩放，按住鼠标左键任意平移画布。

2. **按需展开与像素级工具使用**：
   - 点击右上角「工具栏」展开完整控制条；
   - 点击「取色器」开启 16x 十字放大镜，在画面细节处点击即可一键复制像素色值；
   - 切换底色模式（系统全局跟随 / 透明棋盘格 / 纯黑暗室 / 纯白原纸）；
   - 测试 90° 顺/逆时针旋转与水平/垂直镜像翻转；
   - 点击工具栏最右侧的「收起」按钮随时收回工具栏。
