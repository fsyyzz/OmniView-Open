# OmniView Excel (.xlsx) 示例数据工作簿

本目录包含 OmniView 针对微软 Excel (.xlsx / OpenXML SpreadsheetML) 规范的标准示例文件。

## 📊 包含文件

- **`omniview-budget-report.xlsx`**: OmniView 商业业务总览与预算执行多工作表高保真数据报表。
  - **OpenXML 结构**: 遵循标准 SpreadsheetML 规范（包含 `[Content_Types].xml`、`xl/workbook.xml`、`xl/worksheets/sheet1~2.xml`、`xl/sharedStrings.xml`、`docProps/core.xml` 等）。
  - **工作表内容**:
    - **Sheet 1 (2026年度业务营收与增长)**：涵盖商业授权、CodeGraph 智能索引、DiagramStudio 协同画布与 Office 解析组件的季度收益、SUM 公式自动计算、YoY 同比增长率与状态达成标识；
    - **Sheet 2 (研发及运营预算明细)**：涵盖架构组、前端组、基础设施组与质量工程组的项目负责人、规划预算、执行支出、公式差额扣减与预算执行率风险预警。

## 🎮 确认可用的 8 项核心操作

1. **多工作表无缝切换 (Multi-Sheet Tabs)**：底部工作表标签栏支持在“业务营收与增长”与“研发及运营预算明细”之间秒级切换；
2. **列维度排序与重置**：点击任意表头实现单列升序、降序或一键恢复原始数据顺序；
3. **全文检索与模糊过滤 (Ctrl+F)**：支持搜索数字、负责人姓名、业务品类与状态，并伴随黄色高亮提示；
4. **公式与计算值动态检视**：支持解析并显示 `<f>SUM(...)</f>` 等电子表格公式与预计算结果；
5. **列特征画像与迷你火花线 (Column Profiling)**：点击列画像按钮弹出数值分布统计、最大/最小/平均值与数据类型分析；
6. **单元格一键复制与提示**：点击任意单元格快速复制数值到剪贴板并给出绿色成功反馈；
7. **多格式数据导出**：支持一键将当前工作表无损导出为 CSV、JSON 或 Markdown 表格代码；
8. **缩放调节与全屏检视**：支持 50% ~ 200% 平滑缩放与全屏沉浸大宽表浏览。
