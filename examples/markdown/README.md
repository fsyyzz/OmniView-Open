# Markdown 示例集

这些文件用于验证 OmniView VS Code 插件的 Markdown 阅读体验。安装插件后，可以逐个打开下面的文件并选择 **OmniView 文件渲染器**。

## 示例目录

| 文件 | 覆盖内容 |
| --- | --- |
| [basic-markdown.md](./basic-markdown.md) | 标题、段落、链接、引用、列表和图片占位 |
| [gfm-features.md](./gfm-features.md) | GitHub Flavored Markdown、任务清单、表格和删除线 |
| [code-blocks.md](./code-blocks.md) | TypeScript、Python、JSON、Shell 代码块 |
| [diagrams.md](./diagrams.md) | Mermaid 与 PlantUML 图表 |
| [graphviz-diagrams.md](./graphviz-diagrams.md) | Graphviz / DOT 拓扑图、有向图、网络状态机与多布局引擎 |
| [math-formulas.md](./math-formulas.md) | KaTeX 数学公式、微积分、线性代数、物理学方程与深度学习模型 |
| [consensus-algorithms.md](./consensus-algorithms.md) | 分布式共识机制 (Raft, PBFT, PoW/PoS)、状态机、时序图与证明公式 |
| [technical-guide.md](./technical-guide.md) | 一份更接近真实项目的混合技术文档 |
| [math-and-diagrams-test.md](./math-and-diagrams-test.md) | 数学公式与图片/图表全屏灯箱综合测试 |
| [stability-stress-test.md](./stability-stress-test.md) | 错误边界、缺失图片、超宽表格与极限稳定性压测 |

建议先打开 `basic-markdown.md` 熟悉基础排版，再打开 `diagrams.md` 与 `graphviz-diagrams.md` 体验内嵌图表渲染。

独立图表源文件见上级目录：

- [../mermaid/](../mermaid/) — `.mmd`
- [../plantuml/](../plantuml/) — `.puml`
- [../graphviz/](../graphviz/) — `.dot`
- [../markmap/](../markmap/) — `.markmap`
