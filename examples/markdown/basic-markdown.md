# 产品文档示例

这是一个用于测试阅读器基础排版的短文档。它包含不同层级的标题、段落、链接、引用、列表和行内代码。

## 从这里开始

OmniView 将 Markdown 渲染为适合阅读的文档页面。你可以使用顶部工具栏调整缩放，也可以从左侧大纲快速跳转。

> 好的文档不是把信息堆在一起，而是让下一步行动变得清晰。

### 核心特点

- 保持 Markdown 原文结构
- 支持长文档垂直滚动
- 支持代码块和图表混排
- 链接、列表和引用保持清晰的视觉层级

### 常用链接

- [OmniView 项目说明](../../README.md)
- [Markdown 官方语法](https://www.markdownguide.org/basic-syntax/)

## 行内元素

可以使用 **加粗文本** 强调重点，使用 *斜体文本* 表示语气，也可以使用 `npm run package:vsix` 表示命令。
