### 1.1 评估维度说明

| 维度代码 | 评估维度 | 核心关注指标 | 理想达标基线 |
| :--- | :--- | :--- | :--- |

## 三、逐项功能核心能力深度分解 (Detailed Feature Breakdown)

### 功能 01：Markdown 深度排版与多引擎混排引擎 (`MarkdownViewer`)

* **驱动定位**: 技术写作、API 架构规范、学术笔记与设计文档的全能排版中心。
* **文件支持**: `.md`, `.markdown`。
* **底层引擎与技术栈**:
  * Marked Lexer AST 解析管线；
  * Prism.js 语法着色与语言自动推导；
  * KaTeX 矢量数学公式排版；
  * `LazyViewportBlock` 块级视口虚拟化机制；
  * `DOMPurify` 严格安全防御白名单。
* **核心能力清单**:
  1. **全景内嵌图表混排**: 无缝混排解析 Mermaid、PlantUML、Graphviz DOT、SVG、Excalidraw、Domain Storytelling 与 Markmap 代码块；
  2. **高级扩展语法支持**: GitHub Flavored Markdown (GFM)、Obsidian Wiki-Links (`[[Link]]`)、提示框 Callouts (`[!NOTE]`, `[!WARNING]`, `[!TIP]`)、交互式任务列表 (`[ ]`, `[x]`)、学术脚注 (`[^1]`)、定义列表 (Definition Lists) 与 Emoji Shortcodes (`:rocket:`)；
  3. **表格高级体验**: 超宽表格横向自适应防护、表格列点击即时排序、Markdown 表格一键转可视化图表 (`TableChart`)、全屏高保真表格灯箱 (`TableLightboxModal`)；
  4. **代码块增强**: 一键复制纯代码、带行号高亮、Word/WPS 双列表格剪贴板复制助手 (`wordClipboardHelper`，解决粘贴到 Office 代码缩进变形与背景丢失痛点)；
  5. **工业级 A4 出版打印**: 遵循 `@page` 物理纸张标准，支持双面装订线奇偶交替、页眉页脚动态宏变量（页码、总页数、章节名），提供标准/紧凑/宽版三种出版版心；
  6. **性能与渲染预算**: 实施块级渲染耗时监控 (`renderTimeBudget`)，对超过 80ms 的慢块打标并触发防抖，万行文档滑动零卡顿 (Zero CLS)。
* **交互特性**:
  * 划选文本弹出操作浮动条 (`MarkdownBubbleToolbar`)，支持加粗、斜体、代码、高亮、删除线、引用与链接一键包裹并安全回写源文件；
  * 右侧文档结构大纲侧栏 (`MarkdownOutlineSidebar`)，集成 `useScrollHeadingSpy` 实时视口标题高亮；
  * 双向滚动联动与行号锚定 (`useMarkdownScrollSync`)。
* **后续评估重点**:
  * 评估巨型 Markdown（> 10,000 行、含 50+ 复杂图表）首屏冷启动与滚动 FPS；
  * 评估 Obsidian 复杂 Wiki-Links 路径反查解析的跨平台边界；
  * 评估 A4 打印在不同系统打印机驱动下的分页断行表现。

---

### 功能 02：Mermaid 现代化图表工作台 (`MermaidViewer`)

* **驱动定位**: 敏捷架构设计、时序逻辑验证与系统流转可视化的标准图表环境。
* **文件支持**: `.mmd`, `.mermaid`。
* **底层引擎与技术栈**: Mermaid.js v11+，集成 `mermaidConfig.ts` 自适应主题渲染器。
* **核心能力清单**:
  1. **全语法类型支持**: Flowchart (流程图)、Sequence (时序图)、Class (类图)、State (状态机)、Gantt (甘特图)、Pie (饼图)、GitGraph (分支演进图)、C4 架构图、Entity Relationship (ER 关系图)、Requirement (需求追踪图)；
  2. **高对比度双主题自适应**: 自动根据 VS Code 宿主当前主题无缝切换明亮/暗黑着色，彻底解决传统 Mermaid 暗黑模式下文字黑底黑字不可读顽疾；
  3. **实时分屏与编辑**: 支持左侧代码编辑、右侧即时响应式重绘，字符变动毫秒级防抖响应；
  4. **导出与共享能力**: 支持 300+ DPI 超清矢量 SVG 导出、无损 PNG 导出与一键复制图像至系统剪贴板。
* **交互特性**:
  * 独立视口无级缩放 (Zoom: 20%~500%)、按住中键/拖拽平移画布；
  * 缩放重置与一键自适应居中 (Fit to Screen)；
  * 全屏沉浸式检视模式。
* **后续评估重点**:
  * 评估高复杂度嵌套子图 (Subgraph) 在超大分辨率屏幕下的自动排版稳定性；
  * 评估语法报错时的局部 Diagnostic 提示精准度与光标行号对齐。

### 功能 03：PlantUML 架构建模与多图管理 (`PlantUmlViewer`)

* **驱动定位**: 面向系统分析师与企业架构师的 UML 标准建模与拓扑设计工作台。
* **文件支持**: `.puml`, `.plantuml`, `.iuml`。
* **底层引擎与技术栈**: PlantUML 文本压缩编解码管线（Deflate + 64进制字典） + 离线/本地/远端多实例分发桥接。
* **核心能力清单**:
  1. **全 UML 规范覆盖**: 组件图 (Component)、时序图 (Sequence)、类图 (Class)、用例图 (Use Case)、活动图 (Activity)、部署图 (Deployment)、网络拓扑图 (NwDiag)、C4-PlantUML 宏扩展；
  2. **多图块自动分页管理 (`PlantUmlDiagramTabBar`)**: 单个文件中若包含多个 `@startuml ... @enduml` 块，系统自动提取标题并生成标签页，自由点击切图；
  3. **服务节点灵活配置 (`PlantUmlServerModal`)**: 支持配置私有内网 PlantUML 渲染服务器或本地 Docker 容器，规避敏感业务架构外传风险；
  4. **建模模版库 (`PlantUmlTemplateModal`)**: 内置经典微服务架构、DDD 领域分层、OAuth 2.0 授权时序等标准建模模版，支持一键注入代码。
* **交互特性**:
  * 实时编辑与双栏分屏视图；
  * 矢量平移与缩放画布；
  * 超清 SVG/PNG 导出与剪贴板复制。
* **后续评估重点**:
  * 评估离线无网络环境下基于私有本地 Server 的响应延迟与渲染保真度；
  * 评估超长时序图（> 100 参与者）横向延展时的排版自适应策略。

### 功能 04：Graphviz DOT 复杂网络拓扑引擎 (`GraphvizViewer`)

* **驱动定位**: 计算机网络、调用链路、依赖拓扑、状态机转移图的工业级排版利器。
* **文件支持**: `.dot`, `.gv`, `.graphviz`。
* **底层引擎与技术栈**: `@hpcc-js/wasm`，采用 Web Worker 异步计算多线程解耦架构 + 主线程同步降级保障。
* **核心能力清单**:
  1. **多布局算法全覆盖**: 原生支持 `dot` (层次有向图)、`neato` (弹簧弹力模型)、`fdp` (力导向模型)、`sfdp` (超大规模力导向)、`circo` (环形布局)、`twopi` (放射状同心圆)、`osage` (分块矩形)、`patchwork` (树状矩形填充) 8 大布局引擎；
  2. **WASM 多线程沙箱防护**: 布局运算在独立 Web Worker (`graphviz.worker.ts`) 中异步执行，运算密集型大图不阻塞 UI 渲染主线程；
  3. **沙箱受限降级自愈**: 在 VS Code 强隔离 CSP 禁止创建 Worker 的极严苛环境下，自动平滑回退至主线程 WASM 同步计算；
  4. **安全过滤**: 经过 `graphvizSanitizer.ts` 与 `DOMPurify` 双重清洗，杜绝节点标签中的恶意脚本执行。
* **交互特性**:
  * 工具栏快速切换布局算法，无需修改源码即时对比不同布局视觉效果；
  * 节点与边缘高亮联动；
  * 高清 SVG / PNG 导出与全屏查看。
* **后续评估重点**:
  * 评估万级节点与边缘的大型拓扑图布局计算耗时与内存峰值；
  * 评估不同布局引擎切换时的过渡动画平滑度与节点重叠率。

### 功能 05：SVG 矢量设计与微调工作台 (`SvgViewer`)

* **驱动定位**: 矢量图标、技术插图、架构拓扑的交互式检视、点选微调与代码导出工作台。
* **文件支持**: `.svg`。
* **底层引擎与技术栈**: 原生 DOM 矢量控制网格 + SVGO 净化优化管道 + React 交互式 Gizmo。
* **核心能力清单**:
  1. **图元点选与交互式微调**: 点击画布中任意图元（`<rect>`, `<circle>`, `<path>`, `<line>`, `<text>`），自动浮现 8 向尺寸调节选区控制手柄 (`SvgSelectionGizmo`)；
  2. **贝塞尔路径节点检视**: 选中路径时自动激活控制点锚点 (`SvgPathNodeHandles`, `SvgLineHandles`)，直观查看路径控制点坐标；
  3. **样式与几何检查器面板 (`SvgInspectorPanel`)**:
     * 基础属性: X/Y 坐标、宽度、高度、旋转角度；
     * 样式属性: 填充色 (Fill)、描边色 (Stroke)、描边宽度 (Stroke Width)、透明度 (Opacity)、虚线样式 (Dasharray)；
     * 对齐辅助: 智能对齐、居中分布与图层顺序置顶/置底；
  4. **全链路导出与工程化转化**:
     * 导出为极简优化的 SVGO 矢量源码（剔除冗余编辑器元数据）；
     * 一键生成 React JSX 组件代码 (`<svg {...props}>...`)；
     * 一键生成 Vue 3 模板代码；
     * 一键转换导出为 Data URI (Base64) 字符串；
     * 导出为高清晰度 PNG。
* **交互特性**:
  * 源码编辑器 (`SvgCodeEditor`) 与画布双向双栏实时同步；
  * 画布背景切换（网格、纯黑、纯白、透明棋盘格）；
  * 底部状态栏实时显示光标坐标、图元总数与文件体积 (`SvgStatusBar`)。
* **后续评估重点**:
  * 评估复杂嵌套 `<g>` 分组与 CSS 内联样式图元的逆向解析与精准选区命中率；
  * 评估带有复杂滤镜 (`filter`) 与剪裁蒙版 (`clip-path`) 的图元在缩放操作时的渲染帧率。

### 功能 06：PDF 现代阅读与选区批注阅读器 (`PdfViewer`)

* **驱动定位**: 论文文献、技术白皮书、产品手册与电子凭据的现代化沉浸阅读器。
* **文件支持**: `.pdf`。
* **底层引擎与技术栈**: Mozilla PDF.js v4+，结合 HTML5 Canvas 2D 逐页分块渲染与高精度 TextLayer。
* **核心能力清单**:
  1. **三维排版阅读模式**:
     * 连续滚动流 (Continuous Scroll): 垂直无限流式滑阅；
     * 单页拟真 (Single Page): 居中单页独立排版；
     * 双页画册 (Two-Page Spread): 书籍杂志双叶并排对开排版；
  2. **智能目录大纲树 (`PdfOutlineView`)**: 自动解析 PDF 内部 Bookmark 目录层级，支持折叠展开与点击毫秒级跳转；
  3. **页面缩略图侧边栏 (`PdfThumbnail`)**: 侧栏快速生成微缩预览图，快速定位长文档特定页面；
  4. **全文搜索与多关键词高亮 (`PdfSearchBar`)**: 基于 TextLayer 建立全文词频索引，支持前后匹配跳转与匹配总数统计；
  5. **选区高亮批注与读书笔记抽屉 (`PdfAnnotationsView`)**:
     * 划选文本弹出色彩批注浮层（黄、绿、蓝、红高亮色）；
     * 为高亮标注添加结构化个人笔记与心得；
     * 支持将全文档批注与摘抄一键导出为标准 Markdown 读书笔记；
  6. **高保真打印**: 深度对接系统打印接口，输出矢量无锯齿印刷级物理纸张。
* **交互特性**:

     * 纯白底色 (Pure White): 检视深色设计稿在纯白底下的边界；
     * 暗灰底色 (Dark Gray): 标准视觉校色中性底色；
  4. **几何变换与操作**: 支持图片顺时针 90° 旋转、水平镜像翻转、垂直镜像翻转；
  5. **EXIF 深度元数据透视**: 自动解析相机的拍摄时间、ISO、光圈、快门、焦距、分辨率与设备厂商信息；
  6. **格式无损转换导出**: 支持直接将图像在 PNG、JPEG、WebP 格式之间自由互转导出。
* **交互特性**:
  * 滚轮平滑缩放、鼠标左键拖拽平移；
  * 底部状态栏实时显示图像物理分辨率 (WxH)、当前视口缩放比与取色器当前坐标。
* **后续评估重点**:
  * 评估超大尺寸单图（> 8000x8000 像素）的显存占用与缩放平移流畅度；
  * 评估动画格式（动图 GIF 与动画 WebP）在逐帧播放状态下的 CPU 占用。

### 功能 20：工作台底座与通用平台子系统 (Workbench Platform & Subsystems)

* **模块定位**: 驱动调度、窗口管理、持久化配置与 VS Code 宿主通信的总体操作系统。
* **核心组成部分**:
  1. **多标签页工作台与会话管理 (Workbench Tabs)**:
     * 支持打开多文件独立 Tab，支持标签拖拽排序、关闭其他、关闭右侧；
     * 快速在侧边栏文件树中定位当前激活文档；
  2. **统一配置持久化系统 v2 (`settingsStorage.ts`)**:
     * 架构遵循 v2 Schema 契约，支持跨版本配置安全平滑迁移；
     * 实施严苛的参数安全钳位 (`clampSettings`)，杜绝非法边界值崩溃；
     * 支持导出全量配置 JSON、导入配置以及一键恢复出厂设置；
  3. **本地文件存储与历史回滚栈 (`fileStorage.ts`, `useTextHistory.ts`)**:
     * 维护内存与本地存储的脏数据对比检测；
     * 提供多步撤销/重做 (Undo/Redo) 状态机；
  4. **全主题自适应引擎 (`nativeTheme.ts`)**:
     * 提供 14+ 款经典流行主题（VS Code Dark+, VS Code Light+, GitHub Dark, Dracula, One Dark Pro, Nord, Monokai, Tokyo Night, Solarized 等）；
     * 100% 依托 `--ov-*` 语义化设计令牌，保证在 VS Code 沙箱内与宿主原生 CSS 变量实现像素级自然融合；
  5. **多语言国际化支持 (`i18n.ts`)**: 完整支持简体中文 (`zh-CN`) 与英语 (`en-US`) 双语即时无缝切换；
  6. **双向安全通信协议 (VS Code IPC, `vscode.ts`)**:
     * 基于 `postMessage` 与严苛的 `type` 白名单协议；
     * 实现双向滚动同步 (`useMarkdownScrollSync`) 与双击预览跳转源码行号 (`onOpenSourceAtLine`)；
     * 实现 Webview 离线安全回写保存 (`onContentChange`)；
  7. **安全纵深防御体系 (`diagramSanitizer.ts`)**:
     * 严格执行 DOMPurify HTML/SVG 白名单清洗，剥离 `<script>`, `onerror`, `javascript:` 等恶意载荷；
     * CSP 沙箱强隔离，零外部遥测与无授权网络外联。
* **后续评估重点**:
  * 评估多标签页频繁切换时的内幕组件卸载与内存回收（避免闭包泄露）；
  * 评估极端断电或宿主强制杀进程场景下的本地草稿恢复能力。

## 五、后续评估实施指引与建议路线 (Evaluation Roadmap & Methodology)

建议后续针对上述各功能展开如下四阶段闭环评估：

```mermaid
flowchart LR
    Phase1["阶段一: 功能边界与兼容性验收<br/>(按格式标准跑测试用例)"] --> Phase2["阶段二: 交互人体工学与体验走查<br/>(快捷键/高对比度/动效)"]
    Phase2 --> Phase3["阶段三: 压力极限与性能 Benchmark<br/>(超大文件/内存预算/慢块监控)"]
    Phase3 --> Phase4["阶段四: 安全渗透与降级自愈评审<br/>(XSS 注入/沙箱限制/断电草稿)"]
```

1. **功能边界与标准兼容性验收 (Phase 1)**:
   * 采用 `examples/` 目录下官方提供的覆盖测试用例（包括 `examples/markdown/`, `examples/csv/`, `examples/svg/`, `examples/typst/`, `examples/notebook/` 等）；
   * 验证各格式特有语法的解析完整度，确认无格式解析错乱或语法丢失。
2. **交互体验与视觉人体工学走查 (Phase 2)**:
   * 验证在 14+ 款主题及 VS Code 默认主题下的色差对比度是否符合 WCAG AA 级标准；
   * 走查常用快捷键（如缩放、居中、切页、复制、全屏）的反馈速度。
3. **极限压力与性能基准评估 (Phase 3)**:
   * 使用 `scripts/test-csv-profiling.mjs`、`scripts/test-lazy-viewport-block.mjs` 等测试套件进行定量性能基准度量；
   * 重点监控高频滚动下的 60 FPS 稳帧情况以及长时运行下的垃圾回收 (GC) 行为。
4. **安全加固与降级防御复核 (Phase 4)**:
   * 验证携带恶意 `<script>` 注入、伪协议 URL 与死循环图元代码时的防御表现；
   * 确保全局 React 错误边界与局部 DiagnosticCard 能有效接管异常，保护开发者的工作台持续可用。
